# 🎨 Tablero interactivo con JavaScript

Proyecto académico realizado durante el segundo curso de
Desarrollo de Aplicaciones Web (DAW).

## 🚀 Funcionalidades

- Desplazamiento entre las casillas del tablero.
- Selección de colores mediante clic derecho.
- Pintado de casillas mediante clic izquierdo.
- Limpieza del tablero.

## 🛠️ Tecnologías utilizadas

![Tecnologías](https://skillicons.dev/icons?i=html,css,js)

## 📚 Conceptos trabajados

- Manipulación del DOM.
- Gestión de eventos.
- Funciones y condicionales.
- Modificación dinámica de estilos.

## 💻 Ejecución

Abrir el archivo index.html en el navegador.
